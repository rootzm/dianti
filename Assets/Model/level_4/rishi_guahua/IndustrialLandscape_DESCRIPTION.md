# IndustrialLandscape — Wall Hanging Painting

## Description
A decorative framed wall painting for a dark, industrial/abandoned environment.
This variant features a simple rusted steel industrial frame holding a dark, smoggy cityscape
painting depicting factories and smokestacks. The paint is heavily peeling and flaking, with
rust streaks across the metal frame surface — authentic abandoned-industrial aesthetic.
